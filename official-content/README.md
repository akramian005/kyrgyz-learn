# Официальные курсы

Официальные курсы не хранятся в БД: бэкенд читает их из `*.json` в этой папке при старте
(`OfficialContent`). Один файл — один курс. Если файл невалидный, приложение не стартует
и пишет в лог, какой файл и что с ним не так.

Менять курсы можно двумя способами:

- **В приложении** — админ, вкладка «Админ». Бэкенд после каждой правки сам перезаписывает файл курса,
  новый курс создаётся файлом `course-<id>.json`, загруженные картинки, аудио и видео кладутся
  в `official-media/<имя файла курса>/`. Изменения видны сразу, без перезапуска. Чтобы они попали
  в репозиторий — закоммитьте изменённые файлы здесь; файлы из `official-media/` копируйте на сервер отдельно.
- **Руками** — правкой JSON и перезапуском бэкенда. Пока бэкенд запущен, руками файлы не правьте:
  следующее сохранение из приложения перезапишет файл тем, что у бэкенда в памяти.

Папка настраивается `official-content.dir` (`OFFICIAL_CONTENT_DIR`), по умолчанию `kyrgyz-learn/official-content/`.
На сервере это должна быть папка на диске (volume), а не файлы внутри jar — иначе правки из приложения
некуда сохранить и они пропадут при передеплое.

## Формат

```json
{
  "id": -1,
  "title": "Кыргызский для начинающих",
  "description": "Необязательно",
  "image": "basics/cover.jpg",
  "position": 0,
  "items": [
    {
      "kind": "LESSON",
      "id": -1,
      "title": "Приветствие",
      "description": "Необязательно",
      "items": [
        { "kind": "MESSAGE", "text": "«Салам» — привет", "image": "basics/salam.png", "audio": "basics/salam.mp3" },
        {
          "kind": "QUESTION",
          "text": "Как сказать «привет»?",
          "audio": null,
          "type": "SINGLE_CHOICE",
          "options": [
            { "text": "Салам", "correct": true },
            { "text": "Рахмат" }
          ]
        }
      ]
    },
    { "kind": "VIDEO", "id": -1, "title": "Алфавит", "description": null, "video": "basics/alphabet.mp4" }
  ]
}
```

- **id** курса, урока и видео — обязательные, **отрицательные** (так они не пересекаются с id из БД)
  и уникальные среди всех файлов. Не меняйте и не переиспользуйте их: по ним открываются экраны
  и на них будет ссылаться прогресс. У уроков и видео отдельная нумерация (урок `-1` и видео `-1` — можно).
- id вопросов, сообщений и вариантов ответа не пишутся — их раздаёт бэкенд при загрузке.
- Порядок уроков и видео в курсе, вопросов и сообщений в уроке — порядок в массиве `items`.
  Курсы на главной сортируются по `position`.
- `type` вопроса: `SINGLE_CHOICE`, `MULTIPLE_CHOICE` (у вариантов `correct`) или `ORDER`
  (у вариантов `correctPosition` с 0; вариант без него — отвлекающий).
- `image` у курса — его картинка (в списках курсов и сверху на экране курса), необязательная.
- `image`, `audio`, `video` — необязательные пути к файлам относительно папки медиа
  (`official-content.media-dir`, по умолчанию `kyrgyz-learn/official-media/`). Удобно держать файлы
  курса в своей подпапке: `basics/salam.png` → `official-media/basics/salam.png`.
  Бэкенд раздаёт их по адресу `/media/official/...` (перемотка видео работает). MinIO для официальных
  курсов не используется. Если какого-то файла нет, приложение не стартует и перечисляет пропавшие файлы.
- Медиа из `official-media/` (картинки, аудио и видео) не коммитятся (см. `.gitignore`) — их копируют
  на сервер отдельно. В git хранятся только JSON курсов.
